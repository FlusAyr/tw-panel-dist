# tw-card 状态面板

SillyTavern 状态块 → HUD 卡片渲染器。玩家只需导入一条引导脚本，之后自动更新。

## 安装

1. 酒馆 → 扩展 → 酒馆助手 → 脚本库 → 新建脚本
2. 粘贴这一行：

   ```
   import 'https://gcore.jsdelivr.net/gh/FlusAyr/tw-panel-dist@v3.39.0/boot.mjs'
   ```

3. 名称随便填，比如 `tw-card 引导`，保存
4. 打开任意聊天，状态块会被渲染成卡片；卡片右下角有水印 `tw-card vX.Y.Z`

## 看不到卡片？

- 右下角没有水印 = 脚本没跑起来（检查酒馆助手是否启用、这条脚本是否启用）
- 有卡片但样式旧 = 面板还没更新，等一会或重开聊天
- 面板设置里「引导 v2.2」这行：换仓库后这一版变了，**看到 `2.2` 说明你装的是新的**

## 从旧仓库过来的

旧引导里写死的地址不会变，面板不会自己跳过来。删掉旧脚本，按上面重导一次（只此一次）；聊天记录、世界书、数据库都不受影响。

## 文件

`content/` 下面是世界书、数据库模板、条目与提示词，按需下载；这些不进脚本，要自己在酒馆里导入。
